# Drift Keyboard Shortcuts & Gestures

Quick reference guide for global and studio hotkeys in Drift.

---

## ⌨️ Global Shortcuts (Desktop)

| Action | Windows / Linux | macOS | Description |
|--------|-----------------|-------|-------------|
| **Start / Stop Recording** | `Ctrl + Shift + R` | `Cmd + Shift + R` | Toggles active screen recording |
| **Stop Recording** | `Ctrl + Shift + S` | `Cmd + Shift + S` | Instantly finishes capture and opens Studio |
| **Pause / Resume** | `Ctrl + Shift + P` | `Cmd + Shift + P` | Pauses or resumes current recording session |
| **Add Zoom Marker** | `Ctrl + Shift + Z` | `Cmd + Shift + Z` | Manually marks a camera zoom focus timestamp |

---

## 🎬 Studio Playback Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause video playback |
| `Left Arrow` | Jump backward 5 seconds |
| `Right Arrow` | Jump forward 5 seconds |
| `Click on Canvas` | Add or reposition camera zoom target |
