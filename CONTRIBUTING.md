# Contributing to Drift

Thank you for your interest in contributing to Drift! We welcome contributions from the open-source community.

---

## 🛠️ Development Setup

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **Rust**: Latest stable toolchain (`rustup update`)
- **Git**: Latest version

### Getting Started
```bash
# 1. Fork and clone the repository
git clone https://github.com/diiviikk5/Drift.git
cd Drift

# 2. Install dependencies
npm install

# 3. Start development server with Tauri
npm run tauri:dev
```

---

## 📜 Code Style & Standards

- **Rust**: Format with `cargo fmt` and check with `cargo clippy` before submitting PRs.
- **JavaScript/React**: Use modern ES module syntax with React 19 / Next.js 16 conventions.
- **Commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/) format (`feat:`, `fix:`, `docs:`, `refactor:`, `perf:`).

---

## 🐛 Bug Reports & Feature Requests

- Use GitHub Issues to submit bug reports or feature ideas.
- Provide full reproduction steps, OS version, and console logs when reporting issues.
